# Order Delivery Time Prediction using Machine Learning

# Overview

This project focuses on predicting order delivery time using machine learning techniques based on real-world logistics data. The system analyzes multiple factors such as delivery distance, traffic conditions, driver availability, and city to estimate delivery duration accurately.

# Objective

* Predict delivery time in minutes
* Improve logistics efficiency
* Reduce estimation errors in delivery systems

# Dataset

* Source: Kaggle (Talabat Enhanced Orders Dataset)
* 100,000 records with 23 features
* Key features:

  * Delivery Distance
  * Traffic Level
  * Driver Availability
  * City
  * Vehicle Type

# Technologies Used

* Python
* Google Colab
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn

# Methodology

1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Model Training & Testing

# Machine Learning Models Used

* Linear Regression
* Random Forest Regression
* Support Vector Machine (SVM)

# Results

* Best Model: **SVM (Support Vector Machine)**
* Achieved lowest error (MAPE ≈ 0.25)
* Demonstrated effective prediction capability

# Applications

* Food delivery platforms (Zomato, Swiggy)
* Logistics & supply chain optimization
* Customer delivery time estimation

#  Limitations

* Depends on dataset quality
* Does not include real-time traffic or weather data

# Future Scope

* Use advanced models (XGBoost, Deep Learning)
* Deploy as web/mobile application
* Integrate real-time API
